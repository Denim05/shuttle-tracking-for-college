02 — Problem & Solution

Why Sistec Chalo?

❌ The Problem
  • Students had no real-time visibility of shuttle location
  • Forced to wait outdoors in heat/rain with zero information
  • No way to know if the bus was delayed or already gone
  • Manual logbooks for fleet management → error-prone & slow
  • No safety mechanism for emergency situations on buses
  • Physical ID cards for boarding → easy to lose or forge
✅ The Solution
  • Live GPS tracking — bus position updates in < 2 seconds
  • Arrival notifications — alert when bus is 500m away
  • Per-stop ETA — Haversine-formula calculated server-side
  • God Mode dashboard — manager sees entire fleet live
  • SOS emergency system — instant broadcast to all managers
  • Digital Bus Pass — QR code, revokable, cannot be forged

4 Role-Based Dashboards

Student / Commuter
Primary end-user of the transit system

09 — Security

Production-Grade Security Layers

🔑
Password Hashing
argon2.hash(password)
Memory-hard algorithm — most secure modern standard. Passwords never stored in plaintext.
🎟️
Session Tokens
jwt.sign({ id, role }, secret, { expiresIn: '1d' })
1-day expiry JWTs. Role embedded in token — no server-side sessions needed.
🛡️
HTTP Security Headers
helmet()
Prevents XSS, clickjacking, MIME sniffing, and other common attacks.
⏱️
Rate Limiting
rateLimit({ max: 100, windowMs: 15 * 60 * 1000 })
100 requests per 15 minutes per IP — blocks brute-force attacks.
📦
On-Device Token Storage
flutter_secure_storage / expo-secure-store
Tokens stored in OS encrypted keychain — cannot be extracted by other apps.
🔒
Encrypted Transport
HTTPS + WSS (TLS/SSL)
All traffic — REST and WebSocket — encrypted in transit end-to-end.
🎭
Role-Based Access Control
authMiddleware verifies JWT role on each route
Admin, Manager, Driver, User — each can only access their permitted endpoints.

13 — Key Advantages

Why This Stands Out

⚡
Real-Time with < 2s Latency
WebSocket-based GPS updates from drivers are broadcast to all users in under 2 seconds, making ETA data always fresh and accurate.
💰
Zero Hardware Cost
Drivers' existing smartphones serve as GPS trackers. No expensive proprietary hardware, no vehicle installations, no maintenance overhead.
📍
Geofencing Intelligence
The server automatically detects when a bus enters a 500m radius of any stop and fires targeted arrival alerts — students never miss their ride.
🆘
SOS Safety System
One-tap emergency alert from anywhere in the app broadcasts to all connected managers and admins instantly, with location and timestamp logged permanently.
🔓
100% Open Source
Every dependency — Flutter, Node.js, MongoDB, Socket.io, OpenStreetMap — is free and open source. Zero licensing fees, ever.
📱
Cross-Platform, One Codebase
A single Flutter/React Native codebase deploys to Android, iOS, and Web — ensuring identical features across all platforms with minimal effort.
