# Shuttle Tracking - Flutter

This is the migrated Flutter version of the shuttle tracking app.

## Prerequisites
- [Flutter SDK](https://flutter.dev/docs/get-started/install) installed.
- Android Studio or VS Code with Flutter extension.

## Getting Started

1.  **Open in Android Studio**:
    - Launch Android Studio.
    - Click **Open**.
    - Navigate to `d:\Fontend2\shuttle_tracking_flutter` and select it.

2.  **Install Dependencies**:
    - If dependencies are missing, run:
      ```bash
      flutter pub get
      ```

3.  **Run the App**:
    - Connect your Android device or start an emulator.
    - Run:
      ```bash
      flutter run
      ```

## Project Structure
- `lib/main.dart`: Entry point.
- `lib/screens`: UI Screens (Login, Dashboard, etc.).
- `lib/services`: API and Auth logic.
- `lib/models`: Data models.
- `lib/components`: Reusable widgets.
