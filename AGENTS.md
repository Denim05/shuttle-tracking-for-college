# 🚀 SISTECCHALO Engineering & Humanized Design Guidelines

This workspace is configured for **Elite Humanized Full-Stack Development and State-of-the-Art UI/UX Craftsmanship**.

## 🎯 Guiding Rules

1. **Humanized Professionalism**:
   - Write clear, intuitive, and modular code with friendly naming and self-explanatory architecture.
   - Deliver empathetic user interfaces that provide immediate visual feedback, graceful fallback states, and intuitive error messages.

2. **Visual Aesthetics & Styling**:
   - Modern typography: Crisp pairings with Google Fonts (`Outfit`, `Poppins`, `Inter`).
   - Clean Iconography: Contextual icons wrapped in soft tinted rounded badges.
   - Glassmorphism & Depth: Subtle surface borders, soft layered shadows, and sleek dark/light theme palettes.

3. **Motion & Feedback**:
   - Dynamic micro-interactions with `flutter_animate` (smooth fade-ins, spring curves, slide-ups).
   - Skeleton loading (`shimmer`) for data fetching.
   - Tactile button presses and polished floating snackbars.

4. **Security & Lean Code**:
   - Zero hardcoded credentials; strict RBAC and input validation.
   - High performance, minimal bloat, and verified builds.
